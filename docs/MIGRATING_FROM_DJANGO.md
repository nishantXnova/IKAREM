# Migrating from Django

Typical cost: a week. Say it plainly: this is a rewrite of views, not a
port. URLs, ORM models, middleware settings, and the admin have no
mechanical equivalent — on purpose (no ORM, no admin are standing
decisions, not gaps). What transfers: your data model thinking, your URL
tree, and your test expectations.

## Map

| Django | IKAREM |
|---|---|
| `urls.py` `path()` tree | `@app.get/post/...` routes + `include_router(prefix)` |
| `def view(request)` | `async def handler(req, ...)` (typed params replace manual parsing) |
| `request.GET` / `request.POST` | `req.query` / `await req.form()` / `await req.json()` |
| `JsonResponse` / `HttpResponse` | `JSONResponse` / `Response` / `return {...}` |
| Models + ORM | `DatabaseConnector` strategy + `Schema` validation (SQL stays yours) |
| `django.contrib.auth` + sessions | JWT (`BearerAuth`, `require_roles`) + signed-cookie sessions + CSRF |
| `MIDDLEWARE` setting order | `app.use(...)` order (sessions before CSRF, fail-fast at boot) |
| Django templates | `Templates(dir)` (`ikarem[jinja]`) + `flash()` |
| `manage.py` commands | `ikarem run|check|mcp|new|migrate|worker|inspect` |
| `django.test.Client` | `TestClient` (cookie jar included) |
| Admin | Wanted: `ikarem-admin` (see `docs/ECOSYSTEM.md`) — no built-in |

## Deltas that bite

- No ORM means every queryset becomes SQL through the connector (`?`
  placeholders always). Port model-by-model with the suite green between.
- No settings module: layered `Config` (defaults < kwargs < dict <
  `IKAREM_*` env). Flat beats nested.
- Auth is stateless JWT or signed cookies — Django's session-backend
  auth (DB-backed, revocable server-side) needs a token-blocklist design
  if you depended on instant revocation.
- Migrations are versioned SQL files (`migrations/NNNN_name.sql`), not
  autogenerated. You write both directions.

## Plan

1. Freeze the URL tree; recreate it as routes returning stub bodies.
2. Port models to SQL + connectors; keep Django running to diff row shapes.
3. Views → handlers; forms → `Schema`; auth → JWT/sessions.
4. Cut over behind `mount_asgi()` one subtree at a time.

## Landing snippet (executed in CI)

```python
from ikarem import Ikarem, JSONResponse
from ikarem.testing import TestClient

app = Ikarem(enable_docs=False)


@app.get("/articles/{year:int}/{slug}")
async def article(req, year: int, slug: str):
    return JSONResponse({"year": year, "slug": slug})


@app.get("/health")
async def health(req):
    return {"ok": True}


c = TestClient(app)
assert c.get("/articles/2026/hello-world").json() == {"year": 2026, "slug": "hello-world"}
assert c.get("/health").json() == {"ok": True}
```
